# StarterKit

Personal base Unity package (`com.vkaike2.starterkit`) reused by every future game. Auxiliary
components only — no game logic ever lands here.

**Never write comments in the code.** No XML docs, no `//` explanations, no summary blocks. Record
anything worth explaining in `.claude/MEMORY.md` instead, and keep the class itself clean. The names
carry the explanation.

Read `.claude/MEMORY.md` before designing anything; update it in the same change whenever a decision
outlives the session. The `unity-starterkit` agent in `.claude/agents/` holds the full brief.
