# Starter Kit

A collection of reusable Unity utilities and systems.

## Installation

Unity Package Manager → **Add package from git URL**:

```
https://github.com/vkaike2/StarterKit.git
```

Or add to `Packages/manifest.json`:

```json
"com.vkaike2.starterkit": "https://github.com/vkaike2/StarterKit.git"
```

## Usage

```csharp
using Vkaike2.StarterKit;
```

## Requirements

- Unity 6000.0 or newer
